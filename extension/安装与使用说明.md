# X 视频下载助手 1.0.3 · Chrome / Edge 扩展

这是纯浏览器扩展，不需要启动本地服务，也不需要安装 Python、Node、yt-dlp 或 FFmpeg。

## 已安装旧版的用户

文件更新后，打开 `chrome://extensions`（Edge 使用 `edge://extensions`），在「X 视频下载助手」卡片上点击重新加载，确认版本为 **1.0.3**。然后刷新 X 页面再使用，无需重新选择插件文件夹。

1.0.3 修复了切换页面、整页刷新或重新检测后仍显示上一次视频的问题：切页会清空旧视频缓存，重新检测会读取当前播放器，旧页面迟到的响应会被丢弃；旧视频卡片不能跨页面或跨刷新继续下载。下载历史仍保留在「最近下载」。更新后务必重新加载扩展，再刷新 X 页面。

1.0.2 为每张视频卡片增加帖子文案、作者、封面和查看原帖链接。长文案显示前三行，悬停可查看完整内容；无法获取文案时显示帖子编号。下载记录和新文件名也使用对应标题。封面不可用时保留占位图标。

1.0.1 修复了「重新检测」只重放历史捕获结果、漏掉加载请求后持续显示空列表的问题。现在会主动连接已打开的标签页、扫描已有播放器元数据，并在需要时查询 X 官方公开嵌入数据。检测错误会显示出来。

## 安装

1. 解压交付的 `x-video-downloader-v1.0.3.zip`。
2. Chrome 地址栏打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 打开右上角「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择解压后的 **X视频下载助手** 文件夹。该文件夹内应直接能看到 `manifest.json`。
5. 在浏览器工具栏的拼图菜单中，把「X 视频下载助手」固定到工具栏。

使用源码时，第 4 步选择本项目的 `extension` 文件夹。

## 使用

1. 安装后，先刷新已经打开的 X 页面。
2. 进入视频所在的帖子，播放一次视频。
3. 点击工具栏中的蓝色下载图标。
4. 根据文案、作者和封面确认目标；需要核对时点击「查看原帖」。默认选中最高可用画质，点击「下载视频」。也可以在下拉框选择其他画质。

文件默认进入浏览器下载目录下的 `X视频` 文件夹。勾选「每次下载时选择保存位置」，下次下载就会弹出保存窗口。同名文件使用新文件名保存，避免覆盖。

下载进度、取消和在文件夹中显示，可在扩展的「最近下载」或浏览器下载管理器中操作。关闭扩展窗口不会停止已经开始的浏览器下载。

## 识别范围与限制

- 插件读取 X / Twitter 页面正常加载的网络响应和已有播放器元数据；必要时查询 X 官方公开嵌入数据。仅使用这些数据明确提供的 MP4 地址，保留原文件，不转码。
- 在单条帖子页面，按帖子 ID 筛选，避免把引用帖、评论或其他已加载帖子的视频当成当前视频。
- 在首页时间线，显示当前页面已加载、已识别的 MP4 视频；切换页面和刷新会清空旧页面列表，重新检测会读取当前播放器。建议进入单条帖子后再下载，更容易确认目标。
- 只提供 HLS / m3u8、直播、加密媒体或未在响应中出现 MP4 的视频，当前版本不支持。此时不会把分片冒充完整 MP4。
- 首次安装、更新插件或浏览器重新启动后，若没有识别到视频，请刷新帖子再播放。现在点击「重新检测」会主动扫描已有播放器并尝试公开嵌入数据，不再只是等待未来的网络请求。
- 媒体地址过期或下载返回拒绝访问时，刷新原帖子，再重新检测并下载。网页自身无法访问的视频，插件也不能保证下载。
- X 改动接口结构后，可能需要更新识别逻辑。不能承诺所有视频、账号和浏览器版本都能下载。

## 权限与数据

- `downloads`：调用浏览器原生下载管理器，显示本插件发起的下载。
- `storage`：保存「选择保存位置」选项，以及当前浏览器会话中的视频与下载记录。
- `activeTab` 和 X / Twitter 站点访问：识别你当前打开的页面及其视频信息。
- `scripting`：为已经打开的 X 标签页补充页面检测脚本，减少错过加载时机造成的空列表。
- `cdn.syndication.twimg.com`：X 官方公开嵌入数据的备用识别接口，请求不带账号 Cookie。

本插件没有第三方中转、远程代码、统计服务或收费接口，不读取或导出 Cookie。视频记录使用会话存储；浏览器关闭后会清除，下载的文件保留。

37 项自动化测试已通过，覆盖媒体识别、标题与画质、消息边界、公开数据备用识别，以及站内切页、同地址刷新、重新检测、旧请求迟到、旧按钮失效、检测失败清空旧卡片和弹窗响应乱序。测试使用本地样例和模拟浏览器 API。

开发者可使用 Node 20 运行：

```sh
node --test test/*.test.cjs
```

测试只使用构造的数据，不访问 X，不读取账号，也不下载第三方视频。Node 仅供开发测试，安装与日常使用扩展不需要 Node。
