# X 视频下载助手

**版本：1.0.3** · Chrome / Edge 浏览器扩展 · Manifest V3

在 X / Twitter 页面识别可用的 MP4 视频，按画质下载到本地。每个视频都有帖子文案、作者、封面和原帖链接，方便确认下载目标。

日常使用只需浏览器，**不需要安装 Node、Python、yt-dlp、FFmpeg，也不需要启动本地服务**。

## 1.0.3 更新

修复切换 X 页面、刷新和重新检测后仍显示上一次视频的问题。现在会清空旧页面缓存，重新读取当前播放器，并丢弃旧页面迟到的网络响应；页面变化后，旧的视频卡片不能继续发起下载。最近下载保留为历史记录。

更新后，在扩展管理页点击本插件的「重新加载」，确认版本为 **1.0.3**，再刷新已经打开的 X 页面。

具体修复与验证范围见 [更新日志](CHANGELOG.md)。

## 功能

- **视频标题**：展示帖子文案、作者名称和账号；长文案显示前三行，悬停可查看完整文字。
- **封面和原帖**：通过缩略图及「查看原帖」核对视频。
- **画质选择**：默认选择最高可用画质，也可手动切换。
- **直接保存 MP4**：保留选中版本的原文件，不转码。
- **下载管理**：查看进度、取消下载、在文件夹中显示；关闭弹窗后下载继续。
- **文件命名**：文件名包含标题摘要、帖子／媒体编号与分辨率，同名文件自动区分。
- **主动检测**：读取页面网络响应和已有播放器信息，必要时尝试 X 官方公开嵌入数据。

## 安装

支持 Chrome 111+ 和基于 Chromium 111+ 的 Edge。

### 使用安装包

1. 前往 [Releases](https://github.com/fangxiang97/x-video-downloader/releases)，下载 1.0.3 安装包并解压。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择解压后的 **X视频下载助手** 文件夹，文件夹内应直接包含 `manifest.json`。
5. 在浏览器工具栏的扩展菜单中固定「X 视频下载助手」。

### 使用源码

点击仓库的 **Code → Download ZIP**，解压后按上面步骤操作，第 4 步选择仓库内的 **`extension` 文件夹**。

安装或更新后，请重新加载扩展，并刷新已经打开的 X 页面。

## 使用

1. 打开视频所在的 X 帖子，播放一次视频。
2. 点击工具栏中的「X 视频下载助手」。
3. 根据标题、作者和封面选择目标，需要时点击「查看原帖」。
4. 选择画质，点击「下载视频」。

文件默认保存到浏览器下载目录下的 **`X视频`** 文件夹。勾选「每次下载时选择保存位置」，即可在下载时自行选择目录。

单条帖子页面会按帖子编号筛选；首页时间线显示当前页面已经识别的视频，切换页面或刷新会清空旧列表；点击「重新检测」重新读取当前已加载的播放器。想准确定位目标，建议进入单条帖子再下载。

## 常见问题

### 没有识别到视频

先刷新帖子并播放视频，再打开扩展点击「重新检测」。首次安装、更新扩展或重启浏览器后尤其需要刷新页面。

插件仅支持页面或官方公开嵌入数据提供的 **MP4 地址**。仅有 HLS / m3u8 的媒体、直播和加密媒体暂不支持；网页自身无法访问的视频也不能保证下载。

### 下载失败或地址失效

刷新原帖，重新检测并再次下载。媒体地址可能过期，X 的接口变化也可能影响识别。

### 为什么不同视频的标题一样

同一帖子里的多个视频共用帖子文案，需结合封面和媒体编号区分。获取不到文案时会使用帖子编号作为备用标题。

## 权限与隐私

| 权限或站点 | 用途 |
| --- | --- |
| `activeTab` | 读取当前标签页，定位视频所在页面 |
| `downloads` | 发起下载，显示本插件下载的进度和状态 |
| `storage` | 保存选项及当前浏览器会话中的识别、下载记录 |
| `scripting` | 为已打开的 X 标签页补充检测脚本 |
| X / Twitter 站点 | 识别页面加载的视频和帖子元数据 |
| `cdn.syndication.twimg.com` | 查询 X 官方公开嵌入数据作为备用识别方式，请求不携带账号 Cookie |

插件没有统计服务、第三方中转、远程代码或收费接口，不读取或导出 Cookie。封面仅加载 HTTPS `pbs.twimg.com` 图片，视频下载地址仅接受 HTTPS `video.twimg.com` MP4。识别和下载记录使用会话存储，浏览器关闭后清除；已下载文件仍保留在本地。

## 开发

源码位于 `extension/`，测试位于 `test/`。开发测试使用 Node.js 20+，无第三方 npm 依赖：

```sh
npm test
```

37 项测试覆盖帖子与引用帖关联、媒体地址校验、画质选择、文件命名、消息边界、播放器扫描、公开嵌入数据解析，以及站内切页、同地址刷新、旧请求迟到、旧按钮失效、检测失败清屏和弹窗异步结果乱序。测试使用本地样例，不连接 X，也不下载视频。

界面预览使用模拟浏览器 API，不执行真实下载：

```sh
npm run preview
```

打开终端输出的本地地址即可查看。预览服务仅监听 `127.0.0.1`。
